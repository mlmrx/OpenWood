# Contributing to OpenWood

OpenWood welcomes focused contributions that improve real production craft, reliability, accessibility, and provider portability.

1. Open an issue describing the production problem and the smallest coherent change.
2. Keep domain changes typed and versioned. Never replace artifact contracts with free-form chat state.
3. Add or update tests for workflow gates, agent contracts, persistence, or API behavior.
4. Run `npm run check` before submitting a pull request.
5. Do not commit credentials, unlicensed media, cloned identities, generated assets without provenance, or placeholder UI presented as working capability.
6. Keep new agents narrowly responsible, tool-gated, and independently testable.

By contributing, you agree that your work is licensed under Apache-2.0.
